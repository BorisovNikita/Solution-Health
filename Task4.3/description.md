## Описание схемы
Для аутентификации используется протокол **OAuth 2.0 с расширением PKCE (Proof Key for Code Exchange)** и **OpenID Connect (OIDC)**. 

**Почему выбран этот протокол:**
Мобильные приложения являются «публичными клиентами» (public clients), так как их код можно декомпилировать, и в них нельзя безопасно хранить секреты (client_secret). PKCE решает эту проблему, генерируя динамический код-верификатор, который защищает от перехвата авторизационного кода.

**Способ передачи токена:**
- **Access Token (Токен доступа):** Имеет короткое время жизни (15 минут). Передается в заголовке каждого запроса к API: `Authorization: Bearer <access_token>`. Формат токена — **JWT** (JSON Web Token), который позволяет API Gateway проверять его подпись без запросов к серверу авторизации.
- **Refresh Token (Токен обновления):** Имеет длительное время жизни (30 дней). Хранится **только** в защищенном хранилище операционной системы мобильного телефона (iOS Keychain / Android Keystore). Используется для получения нового Access Token без ввода логина и пароля.
