# Политики Rate Limiting (Ограничение скорости запросов)

| Тип запроса | Лимит | Действие при превышении |
| :--- | :--- | :--- |
| **Публичный:** <br>`GET /api/v1/doctors/search` (Поиск врачей) | **30 запросов / минуту** с одного IP-адреса или устройства (Device ID). | Возврат HTTP-кода **429 Too Many Requests** с заголовком `Retry-After: 60` (указывает, через сколько секунд можно повторить). Запрос блокируется на API Gateway и не доходит до CRM. |
| **Авторизованный:** <br>`POST /api/v1/appointments` (Создание записи) | **5 запросов / минуту** с одного User ID (ID пациента). | Возврат HTTP-кода **429 Too Many Requests**. При повторном нарушении в течение 10 минут — временная блокировка пользователя на 15 минут (HTTP 403 Forbidden) для защиты от ботов и случайных дублей. |
