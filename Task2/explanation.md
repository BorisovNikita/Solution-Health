### Новые интеграции

**1. Мобильное приложение → API Gateway → BFF**
*   **Паттерны:** API Gateway, BFF, Rate Limiting.
*   **Стиль:** Клиент-серверный (Синхронный).
*   **Почему:** Единая точка входа, защита legacy-систем от пиковых нагрузок и агрегация данных под мобильный клиент.
*   **Комбинация:** BFF + паттерн **Cache-Aside** (Redis) для мгновенной отдачи данных без запросов в БД.

**2. BFF → Saga Orchestrator → (Расписание, 1С, Платёжный шлюз)**
*   **Паттерны:** Saga (Оркестрация), Circuit Breaker, Idempotency Key.
*   **Стиль:** Микросервисный (Синхронный).
*   **Почему:** Жесткая последовательность шагов с компенсациями (откатами). Circuit Breaker защищает от падений 1С, Idempotency — от двойных списаний.
*   **Комбинация:** Синхронная оркестрация + **Transactional Outbox** для асинхронной отправки события об успехе в Kafka.

**3. LIS → Event Bus (Kafka) → CRM**
*   **Паттерны:** Saga (Хореография), Pub/Sub, Retry & DLQ.
*   **Стиль:** Событийно-ориентированный (Асинхронный).
*   **Почему:** Полная развязка систем по времени. LIS не ждет ответа CRM, данные не теряются при сбоях.
*   **Комбинация:** LIS использует **Transactional Outbox** (гарантированная отправка), CRM — **Consumer** (чтение из топика с повторами при ошибках).

**4. Event Bus (Kafka) → Сервис уведомлений → Пациент**
*   **Паттерны:** Saga (Хореография), Pub/Sub, Backpressure.
*   **Стиль:** Событийно-ориентированный (Асинхронный).
*   **Почему:** Уведомления не блокируют бизнес-логику. Backpressure защищает сервис от переполнения при пиках (решает проблему RabbitMQ).
*   **Комбинация:** Асинхронное чтение событий + синхронные HTTP-вызовы к внешним SMS/Push-провайдерам.

**5. Расписание → Event Bus (Kafka) → Redis Cache**
*   **Паттерны:** Event-Driven Cache Invalidation.
*   **Стиль:** Событийно-ориентированный (Асинхронный).
*   **Почему:** Мгновенный сброс устаревшего кэша при изменениях, чтобы пациент не записался на отмененный слот.
*   **Комбинация:** Расписание шлет событие через **Outbox**, а сервис кэша выступает **Consumer** и удаляет устаревшие данные из Redis.
